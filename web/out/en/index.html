Three review lanes for every file

The calibrated estimate sends the lowest-risk 30% of files to a fast lane and the highest-risk 10% to strict review; the rest get a standard review. Without external credit scores, a fallback model scores the file.

Mizan checks the SAMA cap on every file

Cap check against gross salary

The new instalment plus existing obligations, against one third of gross salary, or 25% for retirees.

The officer decides

Mizan scores, routes and explains each file. It never approves or rejects a loan, and gender and age are never model inputs.
